# Optical Fashion Website 👓

A responsive optical fashion website built as part of my frontend development journey.

## Technologies
- HTML5
- CSS3
- Flexbox
- Media queries
- Remix Icon

## Features
- Two navigation bars
- Minimal two-circle logo
- Horizontally scrolling headings
- Eyewear image carousel
- Custom orange scrollbar for the text carousel
- Responsive desktop, tablet, and mobile layouts

## What I Learned
- Flexbox layouts
- Horizontal scrolling with `overflow-x`
- Custom scrollbar styling
- Responsive breakpoints with `@media`
- Image sizing with `object-fit`

## Future Improvements
- Add interactive navigation
- Improve accessibility
- Optimize images
- Deploy using GitHub Pages
